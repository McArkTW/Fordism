A token calls this API without a browser — a script, a CI job, a cron. It can only ever do less than your account: what it may do is the overlap between its grants and yours, so a token is a way to hand out fewer permissions, never more. Tokens are yours alone; nobody else's are listed here, and a token cannot create or revoke another.
